# GARUDA — Interactive Engineering Portfolio

A cinematic, engineering-first portfolio for Anurag Prabhuling Swami.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger
- Lucide React
- Optional Three.js / React Three Fiber

## Start

```bash
npm install
npm run dev
```

Open http://localhost:3000.
